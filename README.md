# Internectual Labs

Live website: https://internectual.com

Static HTML, CSS, JavaScript, and locally hosted assets. GitHub Pages publishes
`main` from the repository root. No build step is required.

- `index.html`: lab projects, interactive model demonstrations, and support links.
- `teams.html`: The Team, member biographies, lab contributions, and selected repositories.
- `assets/`: artwork, profile images, service icons, and attribution licenses.
- `CNAME`: this copy’s custom domain; preserve it when updating the site.
- `.nojekyll`: enables direct static-file delivery.
