TK k1 can describe a full group of 20 weights using 32 code bits and a 12-bit scale.

How the numbers are counted

Four bytes hold the 20 one-trit codes. A packed 12-bit scale adds 12 bits: (32 + 12) ÷ 20 = 2.2 bits per weight. This nominal full-group comparison excludes padding and file metadata. It does not measure inference speed or model quality.
